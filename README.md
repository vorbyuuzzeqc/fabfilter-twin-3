## Overview

FabFilter Twin 3 is a versatile polyphonic synthesizer with three oscillators, multiple filter topologies, and an extensive drag-and-drop modulation system for professional sound design.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **FabFilter Twin 3** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Three Oscillators** | Sine, triangle, sawtooth, square, and noise waveforms per oscillator |
| **Multiple Filters** | LP, HP, BP, notch, and comb filters with parallel and serial routing |
| **Drag Modulation** | Drag-and-drop modulation assignment from any source to any parameter |
| **FX Rack** | Built-in chorus, delay, and reverb post-synthesis effects |
